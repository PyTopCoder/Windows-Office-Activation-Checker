# Windows & Office Genuine Activation Checker 🔍

A lightweight, open-source, 1-click batch utility to verify the authenticity and licensing channel of your **Windows (10/11)** and **Microsoft Office (2013–2024/365)** installations.

Many users unknowingly use cracked or temporary KMS/Volume licenses that expire after 180 days or pose security risks. This tool checks the official Windows Software Licensing Management Tool (`slmgr.vbs`) and Office Software Protection Platform (`ospp.vbs`) to give you a clean summary.

## ✨ Features
- **100% Safe & Open-Source:** Pure Windows Batch script—no `.exe` files, no third-party DLLs, no internet connection required.
- **Channel Detection:** Instantly identifies **Retail**, **OEM**, or **Volume (KMS/MAK)** channels.
- **Expiration Check:** Verifies whether your PC is permanently activated or running on a temporary KMS activator.
- **Office Status:** Automatically detects 32-bit and 64-bit Office installations and displays license status.

## 🚀 How to Use
1. Download `Check-Activation-Status.bat` from this repository (or go to the [Releases](../../releases) page).
2. Double-click the downloaded file to run it.
3. Review your Windows and Office license status in the terminal window.
